## 使用说明（先读这 10 条）

1. **顺序即依赖**：阶段 N 依赖阶段 N-1 的产物，跳阶段做会返工。
2. **任务号**：`S<阶段>-<序号>`（S3-02 = 阶段 3 第 2 个任务）；提交信息引用任务号（`feat(identity): S3-02 会话互斥踢旧`）。
3. **每个任务标配**：契约（`.api`/`.proto`）→ goctl 生成 → logic 实现 → 成对迁移 → 单测 → swagger/apitypes 重生成 → 冒烟步。
4. **勾选与进度**：本清单是任务正本；执行进度在 [task/](../../task/README.md) 阶段文档记录（勾选标注日期），不回改本文。
5. **冒烟纪律**：**严禁并发执行**（共享 FIFO 库存池会交叉消耗造成假失败，E1）。
6. 端口：业务服务见 02 §5.2、中间件见 02 §5.3（+20000 规则）；服务共 **18 个**（14 RPC + 2 BFF + iotingest + hello）。
7. 遇到"为什么"：查 02 §17 ADR 对应条目；遇到"坑"：查 02 附录 C（E1~E18）。
8. 前端同学：从对应阶段"前端任务"小节入手，先读 S0-05 契约约定。
9. **启动总口诀**：`compose up -d`（core）→ 迁移 → 种子 → 后端 → 前端；环境问题先跑 envcheck。
10. 卡住了：02 附录 C 坑速查 → 02 正文 → 带 trace_id 问人（Jaeger UI :36686）。

# 阶段 1 · 公共库（micro-common，11 包）

**目标**：11 个包一次建好全平台复用。每包对应一个明确痛点（02 §8），go-zero 已内置的能力**不重复造**（02 §8 末"明确不写的包"清单）。

- [ ] **S1-01 errcode**：万位段分段注册（identity=10000…platform=110000）；`New/Wrap/FromError/ToGRPC`；单测：业务码跨 gRPC status 无损往返。*为什么分段：看码知域。*
- [ ] **S1-02 response**：实现 `httpx.SetErrorHandler` 全局错误出口（02 §3.3 样例）——业务错误 HTTP 200 + `{code,msg}`；认证码 10401~10406 → 401（触发前端单飞刷新/互斥弹窗/提级弹窗）；兜底 500 不泄露内部细节。
- [ ] **S1-03 ctxkit**：With/Get 函数族（uid/sid/client/roles/tenant/data_scope）。*横切信息进 ctx 全链透传。*
- [ ] **S1-04 snowflake**：41bit+10bit worker+12bit 序列；etcd 租约分配 worker_id（退出释放），etcd 不可用退化 `MICRO_WORKER_ID`；`NewAuto`。
- [ ] **S1-05 crypto + 掩码**：argon2id（OWASP 参数）；AES-256-GCM + KeyProvider（EnvKeyProvider 起步，KMS 补位即插，密文头 kid）；`MaskPhone/MaskEmail` 等统一掩码函数 + logx `Sensitive` 接口适配器（**日志脱敏框架机制，02 §11/§13**）。单测：往返 + kid 轮换后旧密文可解。
- [ ] **S1-06 jwtauth**：RS256；access 30min；claims 仅 uid/sid/client/level/jti；**header 内置 kid，验签支持多公钥集合**（轮换期新旧并存）。*权限不进 JWT：塞进去 30 分钟内无法回收。*
- [ ] **S1-07 sessionx**：Redis DB4——sess:{sid} HASH / uid_sessions ZSET / mutex:{uid}:{client} / refresh 轮换+重用墓碑 / login_fail 锁定。单测：互斥踢旧、重用触发全端注销、锁定。
- [ ] **S1-08 authz**：BFF 三层中间件（验签 kid 选钥 → 会话 → client 匹配 → RBAC 每请求 GET Redis auth_cache → 敏感路由 auth_level → ctx 注入 → RPC metadata 桥）；Redis 故障普通路由 fail-open（本地 `collection.Cache` LRU 兜底 + 告警）、FailClose 路径（指令/财务）拒绝。
- [ ] **S1-09 eventbus**：Outbox `Emit(tx,...)` + Envelope 信封（event_id/tenant_id/trace_id/event_type/occurred_at/payload）+ Topic 常量（下划线）+ Relay（SKIP LOCKED + **next_retry_at DB 退避重投 1m/5m/30m ≤16 次 → dead 表**）+ Subscriber（event_dedup 同事务去重 + trace/租户恢复）+ **kq Pusher 封装**（`PushWithKey` 保序 + 同步发送 + 关闭 Flush）。集成测试：全链投递/重复消费/失败重投/dead 表。
- [ ] **S1-10 tenantx**：**SQL 规约支撑包**（ADR-08 配套）——ctx 取租户（MustTenantFromCtx）、`Skip` 显式豁免、Scoped/Exempt 登记表、`limit.PeriodLimit` RPM 分钟桶配额（429 + RateLimit 头）；配套 tenantaudit 规则：租户表 model SQL 必含 tenant_id 条件/列、INSERT 必含 tenant_id 列。
- [ ] **S1-11 testinfra**：三级解析（MICRO_TEST_* → 本机 → testcontainers → Skip）；CI 配 TDengine 容器作业强制全量。
- [ ] S1-12 收尾：全测绿、lint 0 告警、tag **v0.1.0**、micro-server 引用。

**阶段验收**：`go test ./...` 全绿；tag v0.1.0 发布；tenantaudit 对样例工程跑通。

## S3-01 identity_db 表设计（8 表）

### 表：user（字段逐个说理由）

| 字段 | 类型 | 说明与设计理由 |
|---|---|---|
| user_id | BIGINT PK | 雪花 ID。不用自增：多实例会撞、可被遍历 |
| org_id | BIGINT | 归属部门（逻辑外键，可空=未分配） |
| mobile | VARCHAR | **AES-256-GCM 加密存储**，拖库不泄露 |
| mobile_hash | CHAR(64) | HMAC-SHA256 + **唯一索引**。加密列无法建索引，靠哈希列做唯一约束与等值查询 |
| email | VARCHAR | 同样加密 + hash |
| password_hash | VARCHAR(255) | argon2id PHC 串（含盐含参数） |
| types | JSON | 可登录端集合 `["ADMIN_WEB","OPS_APP"]`——单账号多端 |
| status | TINYINT | 1 正常 / 2 禁用 / 3 锁定；禁用即时踢全部会话 |
| locked_until | DATETIME | 5 次失败锁 30 分钟到期时间（自动解锁） |
| party_id | BIGINT | 关联参与方（S4 补充，可空） |
| 通用字段 | — | tenant_id / created_*/updated_*/deleted_at（全表强制） |

其余表：tenant（tenant_code UK/name/plan/quota JSON）、org（parent_id 树）、role（code UK + data_scope JSON）、menu（perm_code UK，菜单-按钮-接口四级）、user_role / role_menu（联合主键）、user_sso_binding（provider + openid UK）。

> **模型实现（ADR-08 口径）**：迁移 SQL up/down 成对 → `goctl model mysql ddl -src ... -cache` 生成 → **custom 文件覆写**：查询方法显式带 `tenant_id = ? AND deleted_at IS NULL`，INSERT 含 tenant_id（02 §6.2 五条约定 + 附录 B checklist）。
> 会话数据在 Redis DB4（sessionx），MySQL 只存"账号是什么"。

- [ ] `migrations/000001_init.up.sql`（8 表 + mobile_hash UK 等索引）与 `.down.sql` 成对

## S3-02 identity RPC 接口（proto）

| 方法 | 入参 | 返回 | 说明 |
|---|---|---|---|
| LoginByPassword | mobile, password, client | token 对、uid、过期 | 锁定校验→argon2id→互斥踢旧→写会话→auth.login 审计 |
| LoginByWechat | code, client | token 对 + need_bind_phone | code2session；未绑手机返回 need_bind |

# 附录 A · 新建一个微服务的 checklist（照抄）

1. `./tools/newsvc.sh <name> rpc|api`（封装 goctl）→ 骨架
2. 端口：RPC 80xx / metrics 91xx **在 02 §5.2 表登记后使用**（预留号不复用，E12）
3. 契约：`.api`/`.proto` → 评审 → goctl 生成 → logic 实现 → **swagger/apitypes 重生成（CI diff）**
4. 建库：`tools/migrate -svc <name> up`；迁移成对 up/down；新表过附录 B checklist
5. 事件：eventbus.Emit（事务内）+ topic 预创建（mqinit）+ Group 名唯一 + ServiceGroup 注册消费（E4）
6. 延迟任务：业务表 next_exec_at 列 + cron 注册表登记（**不建 MQ 延迟**，ADR-09）
7. 出站依赖：登记 02 §10 韧性策略表（超时/重试/熔断/降级一行）
8. 配置：新增项进 micro-deploy/config 正本 → PR → CI 推送 etcd → listener 接入（E15）
9. runbook 五节 → dodcheck 0 FAIL → 冒烟步加入 smoke 工具
10. start_all.ps1 / 02 §5.2 端口表 / README 服务清单同步登记
