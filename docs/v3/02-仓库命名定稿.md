# v3-02 · D1 收尾：前端合仓定名 micro-web

**版本**：v3.0 ｜ **日期**：2026-10-06
**性质**：v2/04 文档 D1（仓库策略：5 仓含前端合仓）的定稿收尾——**5 仓策略维持，前端合仓改名**

---

## 1. 定稿

- 5 仓策略**维持不变**：`micro-common / micro-server / micro-web / micro-desktop / micro-deploy`；
- 前端合仓由 v2 定稿的 **`micro-frontend` 改名为 `micro-web`**（回归 v1 时期的命名）；
- 所有者口径：`frontend` 这个名字"范围有点大"，回归 `web`。
- 客观备注：仓名只是标签，仓内承载物不变——Web 三端（admin/dealer/station）+ 两小程序 + 运维 App + packages/shared；`web` 是 v1 起用过的原名，团队已有认知基础，且与 BFF（面向前端的**服务**）在词汇上彻底区分开。

## 2. 变与不变

| 项 | 口径 |
|---|---|
| 合仓策略（Web + 小程序 + App 一仓） | **不变** |
| 目录结构 `apps/`、`apps-miniapp/`、`apps-mobile/`、`packages/shared/` | **不变** |
| 拆分触发条件（前端 ≥4 人或小程序团队独立 → 按 `apps/*` 目录 filter-repo 抽仓） | **不变** |
| 仓名 | micro-frontend → **`micro-web`** |
